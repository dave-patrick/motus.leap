Before you start

The Android app requires Android 8 or later and a configured HTTPS motus.leap server. Google is the login method. Server-side YouTube authorization and AI provider configuration are separate from Android sign-in.

Connect and sign in

Enter your server address and choose Continue with Google. Authentication opens in the system browser. Complete the browser flow and return to the app. Expired attempts can be restarted. Your session is stored encrypted using Android Keystore and is restored until it expires or you sign out.

Dashboard and library

Use Dashboard for activity, quota and scan actions. Browse your library, playlists and channels, then open an item in YouTube when required. Refresh retrieves current server state. Channel mappings are read-only in the Android companion.

Scans

Queue a playlist sync, full library scan, duplicate scan or misplaced-video scan. Refresh task status and inspect findings. Queued means accepted for processing; it does not mean completed.

AI sorting

Choose a source playlist and video, request a suggestion, and review the proposed destination before confirming a move. Unknown or ambiguous playlist names cannot initiate a move. Review operation status for success and failure counts.

Troubleshooting

For login failures, verify the HTTPS server and mobile authentication endpoints. Check server YouTube authorization if library requests fail. Quota limits and AI provider errors are server concerns. Retry after fixing the reported condition; do not reset app or server data as a first step.

Build and downloads

The repository includes the web backend and native Android client. Android build instructions are in android/README.md. Development APKs are debug signed and require compatible signing to update an existing app. A source ZIP requires build tools. No device installation is performed by this website.
